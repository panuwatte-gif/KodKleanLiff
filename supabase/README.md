# โฟลเดอร์ deploy — โหลดโฟลเดอร์นี้ไปอัปโหลดอย่างเดียว

**ตั้งแต่นี้ไป: อัปโหลด/ลากทั้งโฟลเดอร์ `deploy/` ไปที่โฮสต์ จบ** ไม่ต้องหยิบไฟล์ทีละอัน
(ไฟล์ที่อยู่นอกโฟลเดอร์นี้เป็นไฟล์ต้นฉบับสำหรับแก้งาน ไม่ต้องอัปโหลด)

## ข้างในมีอะไร
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก เด้งเข้าแอป + ประกาศไอคอน/manifest |
| `KodKlean_LIFF.dc.html` | ตัวแอปทั้งหมด (ทุกหน้า + ตรรกะ) |
| `data.js` | ข้อมูลสาธิต (ใช้ตอนยังไม่ล็อกอิน) |
| `config.js` | LIFF ID + ที่อยู่ Supabase |
| `kk-helpers.js` | ปฏิทินไทย · กฎคัดกรอง · CSV/ZIP |
| `support.js` | ตัวรันแอป |
| `manifest.webmanifest` | ทำให้ติดตั้งเป็นแอปชื่อ **KodKlean_Money** |
| `sw.js` | ทำให้เปิดได้ไวและเปิดได้ตอนเน็ตไม่ดี |
| `assets/` | รูปทั้งหมด (ไอคอนแอป ตัวการ์ตูน โลโก้ร้าน รูปสินค้า) |

## วิธีขึ้นเว็บ (Cloudflare Pages / Netlify)
1. ลากโฟลเดอร์ `deploy/` ทั้งโฟลเดอร์เข้าไปวาง (หรือ push เข้า repo แล้วตั้ง build output = โฟลเดอร์นี้)
2. ต้องเป็น **https** เท่านั้น ไอคอนบนหน้าจอถึงจะติดตั้งได้

## ตั้งค่าฝั่ง LINE (ทำครั้งเดียว)
- LINE Developers → LIFF → **Endpoint URL** = URL เว็บที่เพิ่ง deploy (เช่น `https://ชื่อเว็บ.pages.dev/`)
- LINE Login channel → **Callback URL** ใส่ URL เดียวกัน — เพื่อให้กด "เข้าสู่ระบบด้วย LINE" จากเบราว์เซอร์ปกติได้
- เข้าผ่านแอป LINE ก็ยังใช้ได้เหมือนเดิม (ล็อกอินให้อัตโนมัติ)

## ปล่อยเวอร์ชันใหม่แล้วเครื่องยังเห็นของเก่า
เปิด `sw.js` แก้บรรทัด `const CACHE_V = 'kk-money-v1';` เป็น `v2`, `v3`… แล้วอัปโหลดใหม่ แคชเก่าจะถูกล้างเอง
