## หมวดสำหรับ LIFF/แอปการเงิน
- **01_ตัวการ์ตูน_อาเฮีย / _แม่พัน** — คู่ตัวการ์ตูนหลัก ลายเส้นเดียวกัน หลายช่วงวัย (เด็ก→กลางคน ไม่มีวัยแก่)
  ใช้จับคู่ "วัยเดียวกัน" เท่านั้น ห้ามข้ามวัย/ข้ามลายเส้น กระจายวัยในแต่ละหน้า ไม่ซ้ำ
- **02_มาสคอต** — ลูกเจี๊ยบผักชี: ตัวใหญ่(ประกอบหน้า) + ตัวเล็ก(แทนไอคอน)
- **03_โลโก้แบรนด์ในเครือ** — KodKlean Group, กะเพราโคตรคลีน, 5%ข้าวมันไก่, ลูกสาวทำเอง, ไร้มัน, Re:Drink
- **04_โลโก้ร้านsupplier** — Makro, Lotus's, BigC, GoWholesale, Shopee, PP Food, ฟ้าซีฟู้ด, หลอยไก่สด, salmon, เนื้อ
- **05_รูปสินค้า** — กุ้ง3ขนาด, อกไก่, หมู, เนื้อ, แซลมอน, ไข่, ข้าว, ผัก, เครื่องปรุง, บรรจุภัณฑ์
- **06_ไอคอน** — กล้อง, เตือน, กระดิ่ง, กล่องรับของ, สลิป, โฟลเดอร์เอกสาร, ใบกำกับภาษี, ชั้นสต๊อก, คลิปบอร์ด
